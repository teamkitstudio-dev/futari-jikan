# ふたり時間

架空のAI彼女「りょうこ」と日本語で会話するWebアプリの試作版です。外部APIやAPIキーは不要です。返信はキーワードに応じたデモで、生成AIではありません。

## 開発

Node.js 22以上（検証済み: 24.19.0）を使用します。外部パッケージは不要です。

```sh
cd /workspace/futari-jikan
npm ci --ignore-scripts
npm run dev
```

既定ポートは3000です。`PORT`と`HOST`で変更できます。通常起動は`npm start`、検証は`npm test`です。ビルド工程はありません。

### HTML単体で試す場合

`public/index.html`だけを可視化ツールに渡すと、別ファイルのCSSやJavaScript、会話APIが読み込めない場合があります。`npm run build:demo`で生成する`dist/futari-jikan-demo.html`は、CSS・JavaScript・デモ返信を内包しています。通常のブラウザで直接開いて試せます。会話をサーバーへ送信しない独立したデモです。スクリプト実行を禁止する可視化ツールでは会話操作はできません。

## 機能と制限

- 日本語チャット、話題の候補、送信中表示、通信エラー時の再送信
- Enterで送信、Shift + Enterで改行。日本語変換中のEnterでは送信しません。
- スマートフォン対応、会話履歴のブラウザ保存（最大100メッセージ）、確認付きリセット
- 会話内容は返信のため同じアプリのサーバーへ送信されます。サーバーは履歴を保存せず、外部サービスにも送信しません。
- 履歴はブラウザ単位です。共有端末ではリセットしてください。個人情報や秘密は入力しないでください。
- デモ返信は直前の入力のみに反応します。認証、アカウント同期、実際の生成AIとの接続は未実装です。

## 構成と検証

Node.js標準HTTPサーバーとHTML/CSS/JavaScriptで構成し、依存パッケージなしで動作します。`npm test`は実際のHTTPサーバーを一時ポートで起動し、画面と静的ファイルの取得、会話API、空入力・長文・不正JSON、非公開ファイルへのアクセス制限を検証します。

クラウドではプロセスを毎回起動する必要があります。起動後は画面のHTTP 200と`POST /api/chat`への日本語メッセージに対する返信で動作を確認してください。

## GitHub Pages

`npm run build:pages`で自己完結した公開用ファイルを`docs/index.html`に生成します。このファイルと`docs/.nojekyll`をコミットしてください。GitHubリポジトリの Settings → Pages で Source を「Deploy from a branch」、Branch を「main」、フォルダーを「/docs」に設定して保存します。実際のURLとデプロイ結果は同画面で確認できます。非公開リポジトリではGitHubプランによってPagesを利用できない場合があります。公開のためにリポジトリの公開範囲を変更する必要はありません。

Pages版の会話はすべてブラウザ内で処理します。サーバーや外部APIは不要です。画面や返信を変更したら`npm run build:pages`を再実行し、生成ファイルも更新してください。
